## Selected Projects

### [Federated Instruction Tuning of LLMs](https://github.com/jhaSuruchi/OpenFedLLM)

Conducted **TinyLlama-1.1B** experiments on **Alpaca** using PyTorch, Hugging Face Transformers, PEFT, and LoRA. Compared FedAvg and FedProx under IID and non-IID partitions, alongside Flower/Ray vision baselines.

- **Reported result:** Held-out perplexity of **3.71 after 20 rounds**.

### SummarAI — Dialogue Summarization

Independently fine-tuned **PEGASUS on SAMSum** using Hugging Face Datasets and Trainer API. Built a five-stage training pipeline and a **FastAPI** application with an **HTML/CSS** frontend.

- **Approximate test-set ROUGE-1/2/L F1:** **0.42 / 0.18 / 0.36**.

### [Real Estate Web Application](https://github.com/jhaSuruchi/perfect-views)

Developed property listings, search, image uploads, JWT authentication, and Google OAuth. Worked on ANN-based price prediction and collaborative-filtering recommendations.
